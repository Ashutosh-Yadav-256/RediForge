## 1. संक्षिप्त विवरण (Overview)

**RediForge** एक उद्योग-स्तरीय (Enterprise-Grade), इन-मेमोरी कुंजी-मूल्य (Key-Value) डेटाबेस इंजन है, जिसे मौलिक सिद्धांतों (First Principles) के आधार पर बिना किसी बाहरी रनटाइम लाइब्रेरी के विकसित किया गया है। यह Redis के **RESP2 (REdis Serialization Protocol)** वायर-प्रोटोकॉल विनिर्देशों के साथ 100% अनुकूल (Compatible) है। यह मानक Redis क्लाइंट्स (`redis-cli`, `ioredis`, `redis-py`, `Jedis`, `go-redis`) के लिए एक ड्रॉप-इन विकल्प के रूप में तुरंत काम करता है।

इसके साथ एक आधुनिक **वेब प्रबंधन डैशबोर्ड** भी प्रदान किया गया है, जो लो-लेटेंसी WebSocket ब्रिज के माध्यम से लाइव मेमोरी ग्राफ़, की-स्पेस ब्राउज़र, TTL ऑटो-कैलकुलेशन, RBAC एक्सेस कंट्रोल और ब्राउज़र-आधारित इंटरैक्टिव CLI टर्मिनल उपलब्ध कराता है।

## 2. सिस्टम आर्किटेक्चर (System Architecture)

```
                 +---------------------------------------+
                 |            क्लाइंट एक्सेस लेयर         |
                 |  (redis-cli / ioredis / वेब ब्राउज़र) |
                 +---------------------------------------+
                               |                 |
                   मानक TCP पोर्ट 6379     WebSocket / HTTP पोर्ट 8080
                               |                 |
                 +--------------------+   +-----------------------+
                 |    RESP2 पार्सर    |   |    HTTP / WS ब्रिज    |
                 | (स्टेट मशीन इंजन)  |   |  (SSRF सुरक्षा व CORS)|
                 +--------------------+   +-----------------------+
                               \                 /
                            +-----------------------+
                            |     कमांड गेटवे       |
                            | - दर सीमा (Rate Limit)|
                            | - RBAC व OIDC प्रमाणी |
                            | - ख़तरनाक कमांड रोक   |
                            | - पासवर्ड-मास्क्ड ऑडिट|
                            +-----------------------+
                                        |
                            +-----------------------+
                            |     कमांड रजिस्ट्री   |
                            |  (102 RESP2 कमांड्स)  |
                            +-----------------------+
                                        |
     +----------------------------------+----------------------------------+
     |                                  |                                  |
+-------------------+            +-------------------+            +-------------------+
|  मल्टी-DB स्टोर   |            |   पब/सब ब्रोकर    |            |   पर्सिस्टेंस लेयर |
| (16 स्वतंत्र DB)  |            | (चैनल व ग्लोब पैटर्न)|          | (RDB स्नैपशॉट व AOF)|
| - LRU मेमोरी निष् |            +-------------------+            +-------------------+
| - एक्टिव TTL सफाई  |
+-------------------+
```

### मुख्य तकनीकी विशेषताएं:
1. **डिटरमिनिस्टिक RESP2 स्ट्रीमिंग पार्सर**: ज़ीरो-कॉपी बफ़र स्लाइसिंग के साथ TCP पैकेट विखंडन और संयोजन को बिना अतिरिक्त मेमोरी आवंटन के अत्यंत तेज़ी से प्रोसेस करता है।
2. **डेटा संरचनाएं और टाइम कॉम्प्लेक्सिटी**:
   - **Strings** ($\mathcal{O}(1)$): बाइनरी-सुरक्षित स्ट्रिंग्स, 64-बिट पूर्णांक अंकगणित (`INCRBY`, `DECRBY`), बिटमैप संक्रियाएं (`BITOP`, `BITCOUNT`).
   - **Hashes** ($\mathcal{O}(1)$): फ़ील्ड-वैल्यू मैप्स, मल्टीपल रीड/राइट (`HMSET`, `HMGET`).
   - **Lists** ($\mathcal{O}(1)$): दोनों सिरों से पुश/पॉप के लिए डबली-लिंक्ड डेक (`LPUSH`, `RPOP`, `RPOPLPUSH`).
   - **Sets** ($\mathcal{O}(1)$): अद्वितीय मानों का सेट, यूनियन, इंटरसेक्शन और डिफरेंस संक्रियाएं (`SUNIONSTORE`, `SINTERSTORE`, `SDIFFSTORE`).
   - **Sorted Sets (ZSets)** ($\mathcal{O}(\log N)$): संतुलित स्कोर एरे और हैश इंडेक्स, त्वरित रैंक गणना (`ZRANK`) और स्कोर रेंज फ़िल्टर (`ZRANGEBYSCORE`).
3. **डुअल पर्सिस्टेंस सबसिस्टम**:
   - **RDB स्नैपशॉट**: डेटाबेस हेडर और CRC64 चेकसम के साथ समय-समय पर `dump.rdb` में बाइनरी सीरियलाइज़ेशन।
   - **AOF (Append-Only File)**: Write-Ahead ट्रांज़ैक्शन लॉगिंग (`always`, `everysec`, `no` नीतियां) और बैकग्राउंड लॉग कॉम्पैक्शन (`BGREWRITEAOF`).
4. **मेमोरी नियंत्रण और LRU एविक्शन**:
   - सभी 16 डेटाबेस में बाइट-स्तर पर मेमोरी ट्रैकिंग।
   - मेमोरी सीमा पर OOM क्रैश रोकने हेतु `allkeys-lru`, `volatile-lru`, `noeviction` नीतियां।
5. **दोहरे चरण का TTL मॉडल**:
   - पैसिव निष्कासन: कुंजी एक्सेस करने पर तुरंत समय सीमा जांच।
   - एक्टिव सैंपलिंग: हर 100ms में प्रत्येक डेटाबेस से 20 रैंडम कुंजियों की जांच, 25% से अधिक समाप्त होने पर गहन सफ़ाई चक्र।
6. **ज़ीरो-ट्रस्ट सुरक्षा एवं SSRF फ़ायरवॉल**:
   - TCP मूल `AUTH` प्रमाणीकरण।
   - स्टेटलेस HMAC-SHA256 JWT टोकन और Google OIDC RS256 JWKS सत्यापन।
   - लूपबैक पते (`127.0.0.1`), निजी नेटवर्क (RFC 1918), क्लाउड मेटाडेटा (`169.254.169.254`) और IPv4-मैप्ड IPv6 का पूर्ण अवरोध।

## 3. बेंचमार्क प्रदर्शन (Benchmarks)

माइक्रो-बेंचमार्क परीक्षण (`benchmark.js`) परिणाम:

- **रीड थ्रूपुट (GET)**: `820,701 ऑप्स/सेकंड` (100k ऑपरेशन्स 122ms में)
- **राइट थ्रूपुट (SET)**: `449,269 ऑप्स/सेकंड` (100k ऑपरेशन्स 223ms में)
- **RDB स्नैपशॉट रिकवरी दर**: `100.0%` (10,503 / 10,503 कुंजियां सुरक्षित पुनर्प्राप्त)
- **AOF रीप्ले दर**: `100.0%` (4,999 / 4,999 कुंजियां पूरी तरह बहाल)
- **LRU मेमोरी नियंत्रण**: 500KB की सख्त सीमा के तहत 50,000 ऑपरेशन्स बिना किसी क्रैश के पूरे किए गए।

## 4. त्वरित शुरुआत (Quick Start)

```bash
# रिपॉजिटरी क्लोन करें व पैकेज इंस्टॉल करें
git clone https://github.com/Ashutosh-Yadav-256/Build-Redis-In-JAVA.git
cd "Build-Redis-In-JAVA"
npm install

# सर्वर प्रारंभ करें (TCP 6379, Web 8080)
npm start
```

वेब कंसोल: ब्राउज़र में `http://127.0.0.1:8080` खोलें।

परीक्षण चलाएं:
```bash
npm test
# 28 टेस्ट सुइट्स, 153 टेस्ट 100% सफल
```
